# Relatorio-de-produção-digital
Relatório criado com base em um versão física
📦 Relatório de Produção – Controle de Saída de Malas

Projeto desenvolvido para facilitar a contagem e o controle diário de saída de malas, baseado no modelo físico utilizado pela equipe. O sistema foi criado com foco em simplicidade, agilidade e redução de erros humanos no processo.

🚀 Tecnologias Utilizadas

React JS

CSS3

🎯 Objetivo do Projeto

Transformar o processo físico de contagem de malas em uma interface digital simples, permitindo:

Registrar facilmente a quantidade de malas.

Visualizar as ordens do dia.

Aumentar a eficiência da equipe.

Evitar erros de contagem.

🛠️ Funcionalidades Atuais

Contagem dinâmica de malas.

Registro visual baseado no modelo físico.

Organização das ordens do dia.

📌 Próximos Passos (Roadmap)

 Criar um modal para melhor interação do usuário.

 Implementar animações para a finalização de uma ordem.

 Tornar o sistema de liberação (confirmações) totalmente funcional.

 Melhorar o design e aparência geral.

 Criar uma segunda página para exibição quando o número de malas ultrapassar os limites da section atual.
